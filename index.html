Clash for Mac
VPN / 代理配置指南

Clash 本身是代理工具而非傳統 VPN，但在 macOS 上通過 TUN 模式（增強模式）可以實現類似 VPN 的全局流量接管效果。

1. 選哪個客戶端？

客戶端特點推薦下載
ClashX Pro 有增強模式（TUN），支持 rule / global / direct ✓ 推薦 ↓ ClashX Pro.dmg
Clash Verge Rev 開源、界面現代、支持 TUN、持續維護 ✓ 推薦 ↓ Apple M / Intel
ClashX 基礎版、無增強模式、僅系統代理 一般 ↓ ClashX.dmg

2. 核心配置流程

第一步：導入訂閱鏈接

  1. 打開設定

    ClashX Pro → 菜單欄圖標 → Config → Remote Config

  2. 添加訂閱

    點擊 + 添加訂閱 URL（從你的機場 / 服務商獲取）

  3. 拉取節點

    點擊 Update 拉取最新節點列表

第二步：選擇代理模式

Rule 規則
按配置規則分流，國內直連、國外代理
最常用
Global 全局
所有流量都走代理節點
Direct 直連
全部不走代理，直接連接

第三步：開啟增強模式

這是實現 VPN 體驗 的關鍵步驟：

  • 系統代理

    菜單欄 → Set as System Proxy（基礎代理，瀏覽器級別）

  • 增強模式 / TUN

    ClashX Pro：菜單欄 → 增強模式 打鉤
    Clash Verge：設定 → TUN 模式 開啟

⚠️
TUN 模式會創建虛擬網卡接管全部流量，像 VPN 一樣工作。終端、App Store 等不走系統代理的軟件也能被代理。

3. 三種代理模式詳解

模式行為適用場景
Rule（規則）按配置文件規則分流日常上網，國內直連、國外代理
Global（全局）所有流量走代理需要全部流量出國時
Direct（直連）全部不走代理暫時關閉代理

4. 增強模式（TUN）— VPN 體驗的關鍵

ClashX Pro 的 Enhanced Mode 和 Clash Verge 的 TUN 模式 本質相同：在系統層面創建虛擬網絡接口，接管所有 TCP/UDP 流量。

💡
終端代理：若不想開 TUN，也可在終端手動設定：
export https_proxy=http://127.0.0.1:7890

5. 常見場景速查

場景推薦配置
日常上網Rule 模式 + 系統代理（夠用）
終端代理增強模式 / TUN 模式（必開）
所有流量出國Global 模式 + 增強模式
遊戲加速TUN 模式 + 選擇低延遲節點

6. 配置文件關鍵字段

如果你自己編輯 config.yaml：

# 代理端口
port: 7890          # HTTP
socks-port: 7891    # SOCKS5

# 增強模式（TUN）—— 這就是"VPN"體驗的核心
tun:
  enable: true
  stack: system      # Mac 用 system，Linux 用 gvisor
  dns-hijack:
    - any:53

# DNS 防泄露
dns:
  enable: true
  listen: 0.0.0.0:53
  enhanced-mode: fake-ip   # 或 redir-host
  nameserver:
    - 223.5.5.5    # 國內 DNS
    - 119.29.29.29
  fallback:
    - 8.8.8.8      # 國外 DNS
    - 1.1.1.1

7. 快速排錯

問題檢查
瀏覽器不走代理確認 Set as System Proxy 已勾選
終端 curl 不通開 增強模式，或手動 export https_proxy=http://127.0.0.1:7890
部分 App 無法代理開 TUN 模式（它們繞過系統代理）
國內網站變慢檢查規則是否正確，確保國內域名走 DIRECT
UDP 遊戲 / FaceTime需要 TUN 模式 支援 UDP 轉發

8. 總結

Rule 模式 + 系統代理 = 日常首選
開增強模式（TUN） = 當需要「像 VPN 一樣」接管所有流量時用
